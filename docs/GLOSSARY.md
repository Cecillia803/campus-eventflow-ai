# 校园活动发现与模拟报名

聚合分散的校园活动信息，帮助学生发现和理解活动；独立的演示报名用于验证报名、取消与候补流程。本词汇表用于讨论，不表示方案已实现。

## Language

**信息渠道**：发布活动信息的具体账号或网站，例如某学院公众号；平台名称本身不是一个具体信息渠道。

**来源内容**：渠道发布的一篇文章、一个视频或一条笔记，是活动信息的证据，不等同于活动。
_Avoid_: 活动

**活动**：现实中的一次有主题的校园事件，可由多份来源内容共同描述；一份来源内容也可描述多个活动。

**场次**：活动的一次具体举办安排，具有独立的时间与地点。

**报名窗口**：允许提交报名的时间区间，与活动举办时间不同；来源未说明时为未知。
_Avoid_: 有效期

**来源修订**：来源对活动安排的更新，例如延期、取消、地点变更或报名截止时间调整。

**外部报名方式**：主办方公布的实际报名入口或操作说明，不代表本平台掌握报名结果或名额。

**演示报名场次**：后台设置的模拟名额与报名规则，仅用于演示本平台报名流程，不产生学校真实报名资格。

**候补**：未获得演示场次名额但进入等待分配序列的状态，不等同于报名成功。

**活动订阅**：学生主动选择接收某类活动、渠道或指定活动的更新与提醒。

**来源覆盖范围**：本平台已纳入并成功同步的信息渠道和时间范围；不代表全校所有活动。
