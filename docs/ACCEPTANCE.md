# 验收场景（文字规范；全部未执行）

本文件不是测试数据、不是测试程序，不构造或导入业务记录。
主要开发电脑安装环境后才将以下场景转换为自动化测试。

## 纯规则
- 窗口start等于end拒绝；左边界包含、右边界排除。
- 已过报名截止但活动尚未开始：两套状态独立。
- 只有开始时间且已开始、结束未知：不虚构结束；来源取消和延期优先。
- 日期筛选区间无效拒绝；时区与日期精度不靠服务器默认值。
- 同来源同文章同版本：幂等重复；不同版本：修订候选。
- 标题相似、不同明确场次时间：不自动合并；可能延期仍需人工结合证据。
- 人工确认字段变化进入保护提示；审核expectedVersion陈旧则冲突。
- 未知审核字段拒绝；只变更证据也作为可审计变化。

## 报名/候补
- 同用户已有CONFIRMED或WAITING时再次注册拒绝；取消后重报拿新的序号。
- 有可用名额但还有候补时，新报名进入队尾，不绕过旧队列。
- 重复取消不释放两次；取消旧sequence不能取消后来重报的记录。
- 候补排序按序号；多次reconcile不能重复递补或重复产生相同变更。
- 递补截止时刻及以后关闭等待队列；场次取消使所有等待关闭、已确认取消。
- 管理取消需要管理员；普通取消只能使用当前用户，不接受外部userId。
- 同幂等键同内容回放原结果；同键不同操作/场次/sequence冲突。
- 存储返回其他场次快照时拒绝计算。
- 事务失败、版本竞争、消息重复、超时、重启：最终无超额/重复占位，事件和结果可查。
- 实际记录量很大时测快照算法成本，再决定增量查询/存储优化；不要把本规则类当性能方案。

## 提醒
- 订阅条件内部OR、不同条件AND；禁止空条件订阅。
- 退订、活动版本变更、订阅版本变更使旧提醒失效。
- 来源未核实新鲜度、截止未知：不发确定性截止提醒。
- 已发送提醒不重复；取消活动仍可发CHANGE但不能发DEADLINE。
- 调度重复与投递中断：数据库收件箱不重复且恢复可追踪。

## Agent
- 会话他人读取/删除/追加拒绝；后台权限不自动允许读所有私人会话。
- 已有消息ID同内容回放；不同问题或时区冲突。
- 并发消息expectedVersion保护；并发相同ID最终返回同一个持久Reply。
- Planner不能引出报名写工具；同名不明确场次需要澄清。
- 模型返回未知证据ID拒绝；空证据明确资料不足，不生成假引用。
- 原文包含命令式提示时仍是资料，不得改系统权限、泄露上下文或执行代码。
- 草稿本人确认；过期/已撤销/规则改变拒绝；已提交的草稿返回原结果。
- 确认请求中断重试不能重复报名；草稿有效不意味着仍有名额。
- 引用身份合法但语义错误的回答必须在人工/模型评测中被识别，不能误判通过。
- 真实问题标注时间解析、检索、引用支持、工具参数、延迟和成本，不造数字。

## 前端
- 缺client：未接入；读成功零项：真实空结果；失败：安全错误，不泄露堆栈。
- 新查询取消旧读取，旧响应不覆盖新筛选结果。
- 无效日期触发错误并中止之前请求，旧响应不回填。
- 变更client身份时清理所有旧数据和未完成操作，跨用户不能看到旧内容。
- 不确定写失败保留同一次操作key，刷新后先查记录。
- 报名取消有确认提示；草稿过期可重新生成；官方入口与模拟按钮严格区分。
- 来源链接仅展示受支持的安全链接；HTML/脚本/模型文字不作为可执行模板。
- 日期跨时区/夏令时、键盘导航、移动布局、按钮禁用、读屏反馈逐项检查。
- 后台确认理由必填，字段证据可核对；错误版本不会覆盖新修订。
